# Node Features

Needed to decide what each of the 127 nodes has as it's feature vector, going into the GNN alongside the wPLI-derived edges. Not doing any ablation here because of time constraints.

Each node in the graph is an EEG electrode. Separate from the wPLI edges (these are responsible for encoding relationships between electrodes), each node needs its own feature vector. This is what that electrode knows about itself and is independent of its connections to the others. Things that were considered include band-power values, a fuller power spectral density (PSD) vector, differential entropy (DE), electrode spatial coordinates, one-hot electrode identity, or some combination.

Decided to use per-band relative power as the node feature vector. Each node's feature vector is its relative spectral power in each of the frequency bands already being computed for the wPLI edges ( delta, theta, alpha-1, alpha-2, beta, gamma). This is a 6-dimensional vector per node, per epoch or per subject depending on graph-aggregation.md's per-epoch default.

Chosen as the default due to time constraints. Can directly tie it to this project's own strongest evidence. Dzianok et al. (2025) whic is the PEARL-Neuro companion paper found real, regionally-specific relative power differences by APOE/PICALM risk group specifically in delta (higher in double-risk) and alpha-2 (lower in double-risk). thsi was computed per-electrode before being averaged into ROI clusters. Using per-band relative power for the node feature is the easiest way to give the GNN access to exactly the kind of signal already shown to differ by group in this cohort. It's also no extra computation. Relative band power is already being computed as part of the frequency bands pipeline (because band-limited signal is needed to calculate wPLI per band to begin with). Deriving a per-node power value from the same band-limited signal doesnt add much extra. The literature precedent for band/spectral-derived node features is also present across the GNN-EEG-AD-classification papers already seen. Klepl et al. (2022) use full PSD (0–100 Hz, 100-dim). Klepl et al. (2023, AGGCN) use continuous PSD (1–45 Hz, 45-dim, CNN-enhanced). Xu et al. (2025, MF-MGCN, below) use differential entropy per band (5-dim, one scalar per band). All three use some spectral/frequency-derived quantity as the node feature. None of them use raw coordinates or identitu. This also keeps node feature dimensionality low and directly interpretable. Will allow for interpretability if the project is taken in this direction. A 6-dim vector of named band powers is more directly interpretable in a post-hoc explanation than a 45–100-dim continuous PSD vector or a learned embedding.

There id alsdo a direct node feature ablation in the literature. Xu, An, Yang & Hong (2025).

This paper's main model uses differential entropy (DE), not PSD, as the node feature. this means one scalar per electrode per frequency band (5 bands: delta, theta, alpha, beta, gamma), on 19-channel resting EEG. Relevant because the paper hasd an ablation, "MF-MGCNIII," which is identical to the primary model except DE is replaced with PSD as the node feature. Accuracy drops from 96.15% to 93.79%. Author's own conclusion was that "the combination of the graph structure architecture and DE features is irreplaceable. The paper's graph structure is also relevant to the coordinates question raised previously. iIt uses two separate adjacency matrices ("dual-mode connectivity"). One is functional (Pearson correlation between each electrode pair's DE values, similar to the wPLI edges used in this project) and the other is structural (binary matrix -> 1 if two electrodes fall in the same anatomical region per the 10-20 layout, else 0). Spatial/anatomical information enters as a second graph structure, not as an addition to the node feature vector.

The same paper also uses leave-one-electrode-out ablation and found Pz, F7, and F8 the most important channels for AD classification (they had the largest AUC drop on removal), with prefrontal and occipital electrodes (Fp1, Fp2, O1) being the least important. Could use this as a sanity check to compare against once this project's own model produces electrode-level explanations. Need to consider though that it comes from a different population (diagnosed AD) and a sparser 19-channel montage (compare this to 127)

So, DE is a legitimate, evidence-backed alternative to relative band power as a node feature.

Whats not done and why.

- Not running a DE vs nband-power node nfeature ablation, even though Xu et al. has direct evidence that DE outperformed PSD in their setting. This is a good follow-up ablation for this decision if there is time because its back by the literature.

- Didn't add a full continuous PSD vector (Klepl-style, 45–100 dim) as the node feature. Wouldn't add much extra compute but adds node-feature dimensionality (would make interpretability harder if i went in that direction) and there's no in-cohort evidence (unlike band power) that the extra spectral resolution captures something the coarser band split misses for this specific target.

- Not adding electrode coordinates as a second node-feature channel or a second adjacency matrix. Xu et al.'s dual-mode structural adjacency is a good design and a potential extension, but adding a second graph structure is an architecture change beyond node-feature level, and there's no evidence yet (from project's own data or literature) that spatial adjacency adds value beyond what wPLI-derived functional connectivity already captures for this target. Could be a future extension.

- Not using one-hot electrode identity. Would let the GNN memorize per-electrode-position information directly. Risks working against generalization at n=77 subjects. No literarure precedent found yet.
